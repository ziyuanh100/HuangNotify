# HuangNotify

**讓通知，好好留下。**

免費、無廣告、無帳號的 Android 通知紀錄 App。收到通知時保存文字副本，原通知消失後仍可查閱。繁體中文介面、柔和綠色卡片、系統深色模式。

> 0.1.0 為初始測試版本。它是通知備份工具，無法保證捕捉所有通知，也不能還原安裝前已消失的內容。

## 功能

- 通知文字即時保存：來源、標題、內文、發布／接收時間。
- 原通知移除後保留紀錄，記錄系統提供的移除原因。
- 更新歷程：同一個仍有效的通知識別碼更新時，保存內容版本，不膨脹通知總數。
- 今日新增、目前保存、收藏、各 App 筆數與資料庫大小。
- 關鍵字搜尋，依 App／今天篩選；分批載入紀錄。
- 收藏、備註、複製文字、開啟來源 App。
- 暫停記錄、排除來源 App、保存期限（持續保留／7／30／90／365 天）。收藏不自動清理。
- 手動備份與還原：匯入前預覽、完整驗證、交易式合併、識別碼去重。
- 選用密碼加密：AES-256-GCM、PBKDF2-HMAC-SHA256、每份檔案獨立亂數 salt 和 nonce。
- 無 INTERNET 權限、廣告 SDK 或分析 SDK；停用系統雲端及裝置轉移備份，改用明確的手動匯出。

## 安裝與使用

1. 從 [GitHub Releases](https://github.com/ziyuanh100/HuangNotify/releases) 下載測試 APK，或自行建置。
2. 開啟 App，點選「開始保存你的通知」。
3. 在系統通知存取權設定中啟用 **HuangNotify**。
4. 返回 App，確認顯示「正在記錄」，再從其他 App 發送一則測試通知。
5. 移除原通知後，確認 HuangNotify 的紀錄仍存在。

部分 Android 版本對側載 App 有「受限制的設定」。若系統不允許開啟通知存取權，可在系統 App 資訊頁查看對應選項；不同品牌的操作位置可能不同。不要把服務未連線誤認為已在記錄。

初次連線會補存**仍在通知列**的通知；計數的「今日」依本機時區、首次成功記錄時間計算。保存總數是當前資料庫的通知筆數，刪除後會減少，並非終身收到的通知總量。

## 開發與建置

- JDK 17
- Android SDK Platform 36、Build Tools 35.0.0
- Gradle Wrapper 8.13、Android Gradle Plugin 8.11.1
- 最低 Android 8.0（API 26），target API 35
- 原生 Java / Android Views / SQLite，沒有執行期第三方依賴

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
# 啟動模擬器或連接已授權的測試手機後：
./gradlew :app:connectedDebugAndroidTest
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。

Debug APK 僅供測試。正式對外發行前請自行建立並保管 release signing key，使用 Android Studio 的 Generate Signed Bundle / APK。不要提交私鑰、密碼、真實通知或個人備份。不同簽章的 APK 無法直接覆蓋安裝；更換簽章前先匯出資料。CI 每次執行可能產生不同 debug key，不能保證跨次安裝可直接更新。

## 資料與隱私

[隱私說明](docs/PRIVACY.md) · [架構與資料格式](docs/ARCHITECTURE.md) · [手動驗收](docs/TESTING.md)

- 保存 App 實際提供給通知監聽服務的文字，不抓取聊天資料庫、不下載附件。
- 系統可能遮蔽驗證碼等敏感內容；本程式不繞過系統限制。
- 來源的群組摘要通知不另記錄，避免與個別通知重複；如果來源只有群組摘要，該內容不會記錄。
- 暫停、權限關閉、服務中斷或儲存失敗期間，已消失的通知可能漏記。
- 同一來源更新一個通知時，視為同一筆的不同版本；不同 App 的通知聚合方式不同，**通知筆數不等於聊天訊息數**。
- 文字上限每欄 100,000 字元；超出截斷。備份原文上限 20 MiB，匯入最多 100,000 則／200,000 個版本。尚不支援更大型備份。
- 本機資料庫使用 Android App 私有儲存空間；未額外實作資料庫加密或 App 指紋鎖。匯出檔案可選用密碼加密。
- 備份不包含 Android 授權；換手機後需要重新開啟通知存取權。
- 備份流程若因程序重啟或旋轉中斷，請重新操作；不會把密碼寫入磁碟保存。
