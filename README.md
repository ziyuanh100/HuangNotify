# HuangNotify

**讓通知，好好留下。**

免費、無廣告、無帳號的 Android 通知紀錄 App。收到通知時保存文字副本，原通知消失後仍可查閱。繁體中文介面、柔和綠色卡片、系統深色模式。

> 1.0.0-rc.1 為正式候選版本，仍待實機驗收。它是通知備份工具，無法保證捕捉所有通知，也不能還原安裝前已消失的內容。

## 功能

- 通知文字即時保存：來源、標題、內文、發布／接收時間。
- 原通知移除後保留紀錄，記錄系統提供的移除原因。
- 更新歷程：同一個仍有效的通知識別碼更新時，保存內容版本，不膨脹通知總數。
- 今日新增、目前保存、收藏、各 App 筆數與資料庫大小。
- 關鍵字搜尋，依 App／今天篩選；分批載入紀錄。
- 收藏、備註、複製文字、開啟來源 App。
- 記錄開關（狀態持久保存）、排除來源 App、保存期限（持續保留／7／30／90／365 天）。收藏不自動清理。
- 每日自動加密備份：指定資料夾、密碼由 Android Keystore 保護、保留 3／7／14／30 份；讀回驗證成功後才清理本次安裝建立的舊自動備份。
- 手動備份與還原：匯入前預覽、完整驗證、交易式合併、識別碼去重。
- 選用密碼加密：AES-256-GCM、PBKDF2-HMAC-SHA256、每份檔案獨立亂數 salt 和 nonce。
- 預設開啟每次進入 App 檢查更新，可用開關停用；另有每日背景版本檢查與更新通知、手動檢查、正式／測試版頻道。只向 GitHub 讀取公開版本資訊，不上傳通知內容。
- App 內下載更新並驗證 SHA-256、套件名稱、版本及簽章；選用非計量網路自動下載，Android 12 以上可選用系統允許時自動安裝。
- 無廣告 SDK 或分析 SDK；停用系統雲端及裝置轉移備份，備份位置由使用者明確選擇。

## 安裝與使用

1. 從 [GitHub Releases](https://github.com/ziyuanh100/HuangNotify/releases) 下載測試 APK，或自行建置。
2. 開啟 App，依首次設定精靈啟用通知存取權。
3. 在系統通知存取權設定中啟用 **HuangNotify**。
4. 返回 App，開啟「記錄通知」開關並確認顯示「正在記錄」，再從其他 App 發送一則測試通知。
5. 移除原通知後，確認 HuangNotify 的紀錄仍存在。

部分 Android 版本對側載 App 有「受限制的設定」。若系統不允許開啟通知存取權，可在系統 App 資訊頁查看對應選項；不同品牌的操作位置可能不同。不要把服務未連線誤認為已在記錄。

初次連線會補存**仍在通知列**的通知；計數的「今日」依本機時區、首次成功記錄時間計算。保存總數是當前資料庫的通知筆數，刪除後會減少，並非終身收到的通知總量。

## 權限與介面

首次開啟會自動顯示可略過的權限精靈，先引導設定通知存取權，再由使用者選擇是否開啟版本提醒及傳送通知權限。拒絕或略過不會反覆彈窗，可在「設定 → 權限設定精靈」重新操作。從系統設定返回時會重新檢查實際授權狀態，不會把返回誤當作授權成功。

篩選、單選、多選、確認、備份密碼與詳情均使用 App 自訂圓角視窗，支援深色模式、可捲動內容及無障礙勾選狀態。Android 的授權、檔案選擇與安裝畫面仍由系統提供。備份採系統檔案選擇器，不申請全部檔案、定位、聯絡人或相機權限；背景運作調整為選用說明。

## 新版本通知

自動檢查更新預設開啟，可用「設定 → 自動檢查更新」開關停用；已有明確關閉偏好會保留，不強制重新開啟。每次從背景進入 App 都會連線檢查新版，不沿用 24 小時成功快取；支援 ETag 條件請求，並遵守 GitHub 限流的重試時間。切換 App 頁籤與關閉對話框不會重新檢查。另保留約每日的背景檢查與手動檢查。

找到新版會顯示 App 自訂提示，點「現在更新」即可在原 App 下載、顯示進度、驗證並接續系統安裝。可選擇稍後，不中斷通知瀏覽。需要安裝來源權限時提供設定入口；系統安裝確認仍由 Android 提供，無法自訂或略過。若版本缺少 SHA-256 資訊，僅提供官方版本說明頁，不安裝未驗證檔案。

自動下載與系統允許時自動安裝仍預設關閉，需另外開啟。所有安裝都核對 SHA-256、套件、版本與目前簽章。更新會終止舊版程序，完成後提供「重新開啟新版」通知；進入新版時可選「完成並重新開啟」或繼續使用，不強制從背景跳出 App。沒有通知權限也能在 App 內看見更新與完成提示。

GitHub 會收到 IP、一般連線標頭及版本資訊請求，不會收到通知內容；自動備份位置另由使用者選擇。離線、強制停止、系統省電或 GitHub 配額會影響檢查與下載。

**第一版 v0.1.0-alpha.1 沒有更新功能且使用臨時 debug 簽章，無法自行收到提醒。** 請先匯出備份，再移除第一版、安裝新的固定簽章版本並還原。不要在備份成功前移除 App。從 v0.2.0-alpha.1 起，官方 Release APK 使用同一把私密簽章金鑰，之後可覆蓋安裝並保留資料；Actions 的 debug APK 不適用。

## 開發與建置

- JDK 17
- Android SDK Platform 36、Build Tools 35.0.0
- Gradle Wrapper 8.13、Android Gradle Plugin 8.11.1
- 最低 Android 8.0（API 26），target API 35
- 原生 Java / Android Views / SQLite，沒有執行期第三方依賴

```sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
# 啟動模擬器或連接已授權的測試手機後：
./gradlew :app:connectedDebugAndroidTest
```

APK：`app/build/outputs/apk/debug/app-debug.apk`。

Debug APK 僅供測試。正式對外發行前請自行建立並保管 release signing key，使用 Android Studio 的 Generate Signed Bundle / APK。不要提交私鑰、密碼、真實通知或個人備份。不同簽章的 APK 無法直接覆蓋安裝；更換簽章前先匯出資料。CI 每次執行可能產生不同 debug key，不能保證跨次安裝可直接更新。

## 資料與隱私

[隱私說明](docs/PRIVACY.md) · [架構與資料格式](docs/ARCHITECTURE.md) · [手動驗收](docs/TESTING.md)

- 保存 App 實際提供給通知監聽服務的文字，不抓取聊天資料庫、不下載附件。
- 系統可能遮蔽驗證碼等敏感內容；本程式不繞過系統限制。
- 來源的群組摘要通知不另記錄，避免與個別通知重複；如果來源只有群組摘要，該內容不會記錄。
- 暫停、權限關閉、服務中斷或儲存失敗期間，已消失的通知可能漏記。
- 同一來源更新一個通知時，視為同一筆的不同版本；不同 App 的通知聚合方式不同，**通知筆數不等於聊天訊息數**。
- 文字上限每欄 100,000 字元；超出截斷。備份原文上限 20 MiB，匯入最多 100,000 則／200,000 個版本。尚不支援更大型備份。
- 本機資料庫使用 Android App 私有儲存空間；未額外實作資料庫加密或 App 指紋鎖。匯出檔案可選用密碼加密。
- 備份不包含 Android 授權；換手機後需要重新開啟通知存取權。
- 備份流程若因程序重啟或旋轉中斷，請重新操作；不會把密碼寫入磁碟保存。

## 自動備份

在「設定 → 自動加密備份」選擇資料夾、密碼與保留份數。自動備份沿用 `.hnbk` 格式，可用手動還原功能在其他手機輸入原密碼還原。密碼以 Android Keystore 包裝後保存，沒有明文密碼落盤；重新安裝後需重新設定自動備份，已有檔案仍可用原密碼還原。

約每天執行，低電量、省電、強制停止或資料夾失聯可能延後；可隨時立即備份。每份新備份先關閉串流再讀回核對 SHA-256，通過後才清理本次安裝建立的過期自動備份，手動備份與其他檔案保留。失敗顯示原因與最後成功時間。資料夾由雲端供應商提供時，檔案會由該服務保存。單份備份仍有 20 MiB 上限。
