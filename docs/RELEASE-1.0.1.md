# HuangNotify 1.0.1 正式修正版

回報：截圖通知沒有收錄。尚未取得 Samsung A55 的實際通知格式，因此本次處理程式中可確認的相容性問題，不能宣稱已在 A55 重現並驗證。

## 修正

- 移除所有群組摘要一律略過的規則；獨立摘要可以記錄。僅在目前活動通知中存在同 App、同使用者、同群組子通知時略過摘要。
- 補上展開標題、摘要文字與 ticker 的備援；圖片通知沒有文字時明確標示圖片未保存。
- 支援現代 MessagingStyle 的 Person 寄件者及圖片訊息說明；空白或格式不合的欄位不再直接蓋掉可讀內容，單一錯誤訊息不影響其他訊息。
- 文字組合限制維持 100,000 字元，資料庫及備份格式不變，無新增正式 App 權限。

## 邊界

- 保存系統傳入的通知文字與來源，不截取螢幕、不讀取相簿、不下載圖片 URI，不保存截圖圖片本身。
- Samsung 的浮動截圖工具列如果沒有對應通知事件，通知監聽不能收錄。若系統遮蔽內容或省電停止服務，仍受 Android 限制。
- 活動通知查詢失敗時優先保留摘要；如果摘要先到、子通知稍後才到，可能分別留下紀錄，不會事後刪除已保存的內容。

## 驗證

新增圖片摘要、群組子通知、空白／錯誤欄位、ticker、展開標題、現代寄件者及長文字測試。另以獨立 probe APK 經 Android 真正發布帶圖片的群組摘要，驗證通知監聽寫入 SQLite、移除後仍保留、備份格式有效。probe 僅用灰色合成圖片，不包含在公開 APK。

公開 APK 沿用固定官方簽章，可由 1.0.0 覆蓋安裝並保留紀錄；仍維持免費、無廣告、無帳號、MIT 開源。
