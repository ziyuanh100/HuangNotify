# HuangNotify 1.8.0 介面與操作規範

本次沿用綠色品牌與液態玻璃導覽，整合原生 Android 介面，讓通知內容優先、主要目的地固定、返回後能繼續操作。資料庫與備份格式不變；單份備份仍受 250 MiB 與 200 萬歷程雙重限制。

## 視覺系統

- 共用 Ui 的色彩、26sp 頁標題、20dp 卡片圓角、14dp 控制項圓角與至少 48dp 點擊範圍。
- 頁首不再重複大型品牌圖塊；以標題、短說明和一致返回按鈕建立層級。
- 通知卡以來源、時間、標題、全文寬度的摘要排序；次要狀態使用低強度文字，收藏有獨立符號。
- 概覽與分析採用中性表面、綠色數字重點，減少大面積深色區塊。強調色實心按鈕用於主要操作，次要操作採細框或文字按鈕。
- 共用對話框改用明確的關閉按鈕，不再顯示沒有拖曳功能的把手；取消仍走原本的取消事件。

## 導覽與狀態

- 固定目的地：紀錄、收藏、分析、設定。分析頁沿用同一液態玻璃導覽。
- 紀錄與收藏各自保存搜尋、App／日期／圖片條件、歷程搜尋及清單閱讀位置；畫面重建也保留。
- 分析保留期間、App、圖表選擇與瀏覽位置。從分析查看通知後，返回可接續圖表；離開分析可回到原本目的地。
- 備份是設定的子頁，使用一致返回控制；設定／收藏的系統返回回到紀錄。
- 不以離開搜尋框或切換目的地清空搜尋條件。

## 搜尋、版面與可及性

- 篩選控制自動換行，避免選項藏在橫向捲動區。選中狀態除顏色外保留文字、勾選及可及性狀態。
- 無符合結果時提供清除篩選或搜尋的操作；清除篩選仍保留關鍵字。
- 大字體或低高度視窗將上方控制移入可捲動內容，保留清單空間。液態玻璃導覽保留底部安全距離。
- 分析的 App 篩選有直接清除入口；載入狀態明確呈現，舊結果不可觸發錯誤範圍的紀錄導覽。

## 驗證

保留既有搜尋、備份、分析、玻璃切換及升級回歸。新增使用旅程驗證：跨分頁搜尋隔離、畫面重建後保留、閱讀位置復原、分析分頁往返、200% 字體／深色／橫向篩選不重疊與內容可捲動。CI 另以 250 MiB 文字／圖片容量上限與 200 萬歷程界線驗證，並與 1.7.0 同機比較備份速度。

模擬器驗證不等同 Samsung A55 實機或完整 TalkBack 操作驗收。
