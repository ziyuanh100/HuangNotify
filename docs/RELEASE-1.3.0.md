# HuangNotify 1.3.0｜備份速度與操作延續

狀態：功能已實作，裝置、程序中斷及效能驗證進行中，正式 APK 尚待發布。

- 加密備份改為 JSON 直接串流至 HNBK2；最終檔案同步計算 SHA-256，減少重複讀寫，保留儲存後完整讀回驗證。
- 用四個依序游標讀取通知、歷程與圖片引用，減少逐筆 SQL 查詢，保留同時刻歷程順序與圖片共用。
- 旋轉畫面後保留作業、進度、取消入口、選檔狀態與還原設定；切回 App 可接續查看。程序被終止後提示重新操作並清理遺留暫存，手動密碼不落盤。
- 新增自選日期區間及含圖片篩選，可與來源、搜尋及收藏組合，一次清除條件；圖片包括目前或歷程仍保留的圖片。
- 通知診斷新增開始／結束測試、時間／來源／結果篩選、回到畫面更新及資料截斷提示；沒有觀察到事件時保留原因未明的說明。
- 清理圖片前顯示影響通知、唯一圖片數與預估可重用空間，預設保護收藏及共用圖片；結果以實際交易為準。
- 改善診斷儲存失敗處理、深色／大字型篩選及進度顯示。

維持 100 MiB、JSON v3／HNBK2 及原有加密參數，1.2.0 可還原本版產出的備份；舊 v1／v2／HNBK1 還原保留。DB schema 維持 v3，免費、無廣告、無帳號、MIT 開源，沒有新增正式 App 權限或執行期依賴。

## 驗證與效能

完整測試結果、建置提交、原簽章 APK digest 及配對效能表將於通過後補入。效能使用測試 APK 中凍結的 1.2.0 備份原始碼，在同一模擬器、相同合成資料及本機 DocumentsProvider 與新版比較；包含各階段耗時，排除人為選檔時間。效能 APK 與正式 APK 不含相同內容：比較用舊程式及測試工具只在測試 APK。

## 實際限制

切到背景仍可能被 Android 終止程序；外部文件提供者卡住時取消可能延後。加速不代表各手機、雲端位置均達到同一百分比。Samsung A55 原始截圖漏記及長時間省電背景情境仍須實機驗證，不能把診斷改善當成已修復該問題。圖片每則 4 張、每張 256 KiB／1440 px 限制維持。
