# HuangNotify 1.3.0｜備份加速、操作延續與進階篩選

本版優先處理備份速度，並改善備份操作延續、通知查找及漏記排查。免費、無廣告、無帳號、MIT 開源，沒有新增正式 App 權限或執行期依賴。

## 更新內容

- 調整 JSON 輸出緩衝，改用四個依序游標讀取通知、歷程與圖片引用，減少逐筆查詢。
- 加密備份直接串流至 HNBK2，生成最終檔時同步計算 SHA-256，減少完整明文檔與重複讀寫；保留原有加密參數及儲存後完整讀回驗證。
- 旋轉畫面後保留同一備份作業、進度、取消入口、選檔狀態與還原設定。切回 App 可接續查看；程序被終止後提示重新操作並清理遺留暫存，手動密碼不落盤。
- 新增自選日期區間及「有圖片」篩選，可搭配來源、搜尋、收藏，一次清除條件；目前或歷程仍有保存圖片都能查到。
- 通知診斷新增開始／結束測試、時間／來源／結果篩選及 200 筆截斷提示，不收集通知正文、圖片或通知 key。
- 清理圖片前顯示影響通知、唯一圖片數與預估可重用空間，預設保護收藏及共用圖片。
- 改善深色／200% 字型的選擇符號、日期欄位及操作按鈕排版。

## 備份速度

以下為 Android 15／API 35 模擬器、相同合成資料及本機文件提供者的五次配對量測中位數；每組先暖機一次，包含建立、儲存及讀回驗證，排除人為選檔時間。基準使用測試 APK 中凍結的 1.2.0 備份程式，並非兩份正式 APK 的實機比較。

| 加密備份資料 | 輸出 MiB | 原本秒數 | 新版秒數 | 時間縮短 |
| --- | ---: | ---: | ---: | ---: |
| 文字 | 9.80 | 6.036 | 1.311 | 78.3% |
| 文字 | 50.01 | 26.074 | 2.367 | 90.9% |
| 文字 | 99.50 | 52.615 | 3.896 | 92.6% |
| 圖片 | 9.68 | 12.279 | 1.431 | 88.3% |
| 圖片 | 49.51 | 55.140 | 2.460 | 95.5% |
| 圖片 | 98.38 | 108.691 | 4.373 | 96.0% |

全部 16 組加密／未加密情境完成，50／接近 100 MiB 加密備份均達成至少縮短 30% 的工程目標；小型備份沒有超過 10% 的中位數退步。大量短通知、歷程及刪除後仍約 100 MiB 的資料庫也完成比較。各資料集在各自同一模擬器配對；不同資料集可能使用不同 runner，不宜直接比較彼此絕對秒數。

[完整效能表與量測限制](https://github.com/ziyuanh100/HuangNotify/blob/main/docs/benchmarks/1.3.0-api35.md)。本次 Release 附上原始五次量測、階段耗時、取樣記憶體／PSS／暫存及程序 I/O 的 `backup-performance-1.3.0-api35.json`。

## 實際限制

模擬器的加速幅度不代表各手機或雲端位置均相同；尚未完成 Samsung A55、雲端文件提供者的速度與通知寫入延遲定量實測。快照完成後仍可寫入通知已有回歸驗證。取樣記憶體／暫存不保證捕捉真正峰值，程序 I/O 計數也不等於儲存裝置的實體讀寫量。

切到背景仍可能被 Android 終止程序；外部文件服務卡住時取消可能延後。Samsung A55 原始截圖漏記與長時間省電情境仍待實機驗證，本版的診斷改善不代表已修復該案例。圖片仍為每則 4 張、每張 256 KiB／1440 px。
