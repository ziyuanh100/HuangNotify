舊／新各次輸出長度相同，完整儲存後讀回校驗保留。全部工程目標通過：大型加密至少縮短 30%，小型中位數不退步超過 10%。輸出 MiB 是實際檔案長度，包含加密容器開銷；「大量短通知」約 7.63 MiB，不能當作正好 10 MiB。刪除後情境保留 19 則通知、約 9.8 MiB 輸出，但資料庫實體仍約 99.84 MiB；測試資料庫刻意停用 auto-vacuum，沒有變更正式 App 設定。原先被模擬器縮小的刪除情境結果已排除。

總時間包含目的檔建立、快照、JSON／加密、儲存與讀回驗證及作業暫存關閉，排除人為選檔及測試目的檔最後刪除。原始 JSON 另附首次執行、每階段耗時、每 100 ms 取樣的 Java used heap／PSS／暫存，以及 `/proc/self/io` 差值。取樣可能漏過真正峰值；檔案快取、取樣本身及其他程序內 I/O 會影響計數，不能當成實體磁碟耗損數據。

不同資料集可能使用不同 runner；只應在同一資料集比較新舊路徑。這是同一 debug 測試 APK 的資料路徑比較，並非兩份正式 APK 的實機測速。不宣稱 Samsung A55 或雲端備份有相同加速；實機通知寫入延遲與完整背景行為仍待量測。
