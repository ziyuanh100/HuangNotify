# HuangNotify 1.0.0

目標：可靠保存通知、能還原的加密備份、可驗證的 App 更新。維持免費、無廣告、無帳號、MIT 開源。

目前為 `1.0.0-alpha.1`，功能已進入實作；不代表達成正式版實機驗收。

## 本版範圍

| 項目 | 行為 |
| --- | --- |
| 記錄開關 | 主頁與設定使用同一個持久偏好，區分暫停、缺少權限、未連線、儲存錯誤與正常記錄 |
| 自動備份 | 每日加密、指定資料夾、立即備份、保留份數、最後成功與錯誤狀態；驗證新備份後清理舊檔 |
| App 內更新 | 下載進度、官方網址與大小上限、SHA-256、套件／版本／簽章檢查；使用系統安裝 session |
| 選用自動更新 | 非計量網路下載，Android 12 以上嘗試自我更新；需要系統確認時通知使用者 |
| 可用性 | 自訂開關與卡片視窗、深色、大字型、TalkBack 與可捲動內容 |

## 發布順序

1. Alpha：自動化測試通過、簽署測試 APK，驗證核心流程。
2. Beta：用相同固定簽章驗證舊版覆蓋升級及真實自我更新；修正回報。
3. RC：完成 Samsung A55／Android 16 長時間記錄、重開機、省電及還原演練。
4. 1.0.0：完成下列門檻後才移除測試版標籤，不預先承諾日期。

## 正式版門檻

- 從官方 0.2／0.3 覆蓋升級，通知、版本、收藏、備註與設定保留。
- 暫停後不新增、重新開啟後新通知恢復；未授權、斷線與錯誤狀態不顯示「正在記錄」。
- 加密備份在另一部手機可用原密碼還原；錯誤密碼、損壞或中斷不修改現有資料。
- 資料夾權限撤銷、裝置離線、磁碟滿、程序終止時不會誤刪既有備份；超額清理只限本次安裝建立的自動檔。
- 真實簽署 APK 更新：正常、下載中斷、驗證拒絕、安裝拒絕／取消、需要確認及系統允許免確認等分支。
- Samsung A55／Android 16 實機完成至少 48 小時觀察，包含鎖屏、省電、重開機與權限撤銷；保留無法保證零漏記的說明。
- 無通知正文、備份密碼或私鑰進入網路請求、公開倉庫與診斷日誌。

圖片與附件、App 生物辨識鎖、資料庫額外加密、大型串流備份、進階統計與批次管理另行安排。
