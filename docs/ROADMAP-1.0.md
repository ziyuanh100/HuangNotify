# HuangNotify 1.0.0

目標：可靠保存通知、能還原的加密備份、可驗證的 App 更新。維持免費、無廣告、無帳號、MIT 開源。

目前發布 `1.0.0` 正式版，整合候選版已完成的功能與修正。正式版使用無後綴版本號及 GitHub 正式發布標示；驗證範圍與已知限制如實公開，未完成的實機觀察不標記為已通過。

## 本版範圍

| 項目 | 行為 |
| --- | --- |
| 記錄開關 | 主頁與設定使用同一個持久偏好，區分暫停、缺少權限、未連線、儲存錯誤與正常記錄 |
| 自動備份 | 每日加密、指定資料夾、立即備份、保留份數、最後成功與錯誤狀態；驗證新備份後清理舊檔 |
| App 內更新 | 下載進度、官方網址與大小上限、SHA-256、套件／版本／簽章檢查；使用系統安裝 session |
| 選用自動更新 | 非計量網路下載，Android 12 以上嘗試自我更新；需要系統確認時通知使用者 |
| 可用性 | 自訂開關與卡片視窗、深色、大字型、TalkBack 與可捲動內容 |

## 發布與驗證

- 1.0.0 使用固定官方簽章，versionCode 8，可由官方 0.2 以後的版本覆蓋安裝。CI 另以相同 runner 的 debug 簽章實際驗證 RC.2 → 1.0.0 的系統安裝確認、資料保留與重新開啟。
- 維持記錄開關、完整來源選擇、搜尋、收藏、歷程、加密備份與 App 內更新。
- 自動檢查維持預設開啟，更新頻道改為預設只接收正式版；保留使用者明確設定的頻道。
- 公開 Release 不標示 Pre-release，提供正式 APK 與 SHA-256；版本檢查可在正式頻道收到更新。

## 持續驗證與已知限制

- Samsung A55／Android 16 至少 48 小時鎖屏、省電、重開機及權限撤銷觀察，以及跨手機加密還原尚未完成。
- 系統未送出的通知、遮蔽的敏感文字與工作設定檔／安全資料夾隔離仍受 Android 控制，不能保證零漏記。
- 各品牌安裝來源限制、磁碟滿、雲端檔案提供者與背景排程等實機情境仍持續驗證。
- 後續問題以修補版本處理，不將「正式版」描述為已驗證所有手機及所有 App。

## 後續版本

圖片與附件、App 生物辨識鎖、資料庫額外加密、大型串流備份、進階統計與批次管理另行安排。
