# HuangNotify 1.2.0｜大型備份與通知診斷

- 單份備份由 20 MiB 提高到 100 MiB，包含文字、圖片 Base64、歷程與設定；不限制整個通知資料庫為 100 MiB。
- 手動及每日自動備份改為逐筆 JSON v3、HNBK2 分段 AES-GCM 與檔案處理，減少大型備份記憶體用量。手動作業提供階段進度與取消，輸出後讀回驗證。
- 保留 v1／v2 JSON 與舊 HNBK1 還原（舊加密仍限 20 MiB）；新版備份需要 1.2.0 以上。還原預覽、重複匯入與衝突交易回滾保留。
- 新增本機通知診斷：連線、收到、成功、重複、暫停、來源排除、摘要及失敗狀態；最近 200 筆，可關閉、清除、重新連線及自行匯出。無通知正文，不自動上傳。
- 儲存概況顯示圖片用量，支援只清除圖片並保留文字、歷程及備註，預設保護收藏。清理後的 DB 空間可重用，檔案不一定縮小。
- 改善空間不足、權限失效、密碼／檔案損壞與驗證失敗提示；失敗保留原有紀錄及既有自動備份。

免費、無廣告、無帳號、MIT 開源，無新增正式 App 權限或第三方執行依賴。沿用固定 release 簽章，可覆蓋官方舊版。

圖片每則 4 張、每張 256 KiB、1440 px 限制不變。無法記錄來源未發出、系統未送達或未授權的內容；Samsung A55 截圖漏記仍須實機診斷，不宣稱本版已修復。大型備份需要足夠私有暫存空間。畫面重建或程序終止後請重新操作備份；外部提供者卡住時取消可能延後。
