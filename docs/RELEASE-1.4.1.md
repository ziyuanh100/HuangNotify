# HuangNotify 1.4.1｜懸浮玻璃導覽與操作介面

- 底部導覽改為懸浮玻璃膠囊。切換頁籤時，選取標記會滑到對應位置。支援背景模糊的裝置會即時模糊導覽列後方的內容，其他裝置以半透明漸層呈現。
- 設定開關可點按整列。核取方塊和單選鈕採固定尺寸，並使用圖形標示選取狀態。
- 畫面較窄或字體放大時，對話框的確認與取消按鈕會改為上下排列。列表底部留有空間，最後一列可完整顯示在懸浮導覽上方。

已安裝正式版的使用者可開啟原本的 HuangNotify，前往 **設定 → 檢查新版本 → 現在更新**。正式 APK 沿用原套件及簽章，可直接覆蓋安裝並保留原有通知、圖片、收藏、備註及設定。支援 Android 8.0 以上。
