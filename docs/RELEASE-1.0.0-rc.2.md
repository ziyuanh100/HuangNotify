# 1.0.0-rc.2 正式候選版

修正回報：「無法選擇手機裡全部的 App」。先前來源清單只讀取資料庫中的通知來源與排除設定，尚無通知的已安裝 App 不會列出。

- 改從 Android PackageManager 取得目前使用者的已安裝 App，包含系統、停用、無桌面圖示及尚無通知的來源。
- 合併歷史紀錄與舊排除設定；同名 App 以套件名稱區分，來源不重複。
- 新增名稱／套件搜尋、全部／一般／系統／歷史分類、目前結果全選與取消選取、允許記錄數量。
- 回收式清單支援大量 App；自訂卡片選項與固定底部儲存／說明／取消按鈕。
- 選擇先暫存，按儲存後原子寫入；取消不修改原設定。原本未排除的來源仍預設允許。
- 清單僅本機使用，不傳送到 GitHub。Android 11 以上新增 QUERY_ALL_PACKAGES 宣告；若未來上架 Google Play，需另外完成該商店的權限用途審核，這次僅發布 GitHub APK。

此版本修正「清單不完整」，不宣稱已證明所有 App 的所有通知均可記錄。來源 App 未發送通知、系統遮蔽文字、通知存取權中斷、省電與個人／工作設定檔隔離仍可能影響記錄。

正式版前仍需 [實機驗收清單](RELEASE-1.0.0-rc.1.md)：Samsung A55／Android 16 的 48 小時背景觀察及跨裝置還原尚未完成。仍維持免費、無廣告、MIT 開源；公開 APK 沿用官方固定 release 簽章。
