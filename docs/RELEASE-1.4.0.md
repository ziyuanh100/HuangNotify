# HuangNotify 1.4.0｜通知介面全面改版

- 通知依日期分組，捲動時仍可使用搜尋，以及 App、日期與圖片篩選。首頁集中顯示記錄狀態、暫停開關和通知數量。
- 通知詳情將收藏與複製放到上方，並分區顯示內文、圖片、備註和更新歷程。
- 設定依記錄、備份、診斷和更新分組。收到新通知時，設定頁會保留捲動位置。
- 來源清單顯示 App 圖示，並可篩選已排除的 App。整體介面採森林綠與萊姆色，跟隨系統的淺色與深色模式。

已安裝正式版的使用者可開啟原本的 HuangNotify，前往 **設定 → 檢查新版本 → 現在更新**。正式 APK 沿用原套件與簽章，直接覆蓋安裝可保留原有通知、圖片、收藏與備註。支援 Android 8.0 以上。
