# HuangNotify 1.1.0｜通知圖片

- 保存通知 BigPicture、圖片 Icon 與已授權本機 MessagingStyle 圖片訊息，詳情可看縮圖、縮放並另存 PNG。
- 每則最多 4 張，壓縮為最長邊 1440 px、每張 256 KiB 的 PNG；圖片原檔可能較大，保存的是壓縮預覽。URI 最多 4 MiB，單次讀取限制 2 秒，失敗保留文字。
- 不掃描相簿、不直接下載網路／file:// 圖片、不保存 App 頭像，無新增正式 App 權限。設定可關閉新圖片記錄，既有圖片仍保留。
- 圖片變更留下歷程、相同圖片共用空間，刪除與到期清理會移除不再被引用的圖片，收藏仍受保護。
- SQLite v1 → v2 保留既有紀錄、收藏、備註與歷程；備份 JSON v2 包含圖片，仍可匯入 v1。單份含圖片總上限維持 20 MiB，加密容器不變。

只處理 Android 實際傳給 App 的通知與圖片，無法保存安裝前已消失、未授權或來源未提供的內容。浮動截圖工具列沒有通知事件時無法收錄。Samsung A55 實際漏記案例尚未確認，不能宣稱圖片功能已修好該問題。

維持免費、無廣告、無帳號、MIT 開源；公開 APK 沿用固定簽章。驗證結果將附在發布說明與 TESTING.md。

Android 8 的私有圖片 URI 不會自動授權給通知監聽器；只有來源已提供可讀權限時才能複製，否則仍保留文字並顯示圖片未保存。BigPicture 直接附帶的圖片不需要這項 URI 授權。
