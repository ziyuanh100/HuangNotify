# HuangNotify 1.0.0 正式版

本版為正式發布，versionName `1.0.0`、versionCode `8`，GitHub Release 不標示 Pre-release。

## 功能與修正

- 保存通知文字、更新歷程、搜尋、統計、收藏與備註。
- 記錄開關、來源排除與保存期限；來源清單包含目前使用者已安裝的 App、系統 App 與尚無通知的 App，支援搜尋、分類與批次選擇。
- 手動及每日加密備份、讀回驗證後再清理舊檔；停止備份與匯入衝突處理。
- 每次進入 App 檢查更新、App 內下載／驗證／接續系統安裝，完成後可重新開啟；下載及安裝中斷可重試。
- 預設只接收正式版，保留使用者明確設定的測試版頻道偏好；自動檢查預設開啟，自動下載與自動安裝仍另行選用。
- 免費、無廣告、無帳號、MIT 開源；已安裝 App 清單及通知不傳送到 GitHub。

## 更新相容性

官方 APK 沿用固定 release 簽章，可由 v0.2.0-alpha.1 及以後的官方 Release APK 覆蓋安裝並保留資料，建議更新前備份。首版 v0.1.0-alpha.1 與 Actions debug APK 的簽章不同，不能直接混用。

## 驗證範圍

Android 8／15／16 的自動化測試、建置與 Lint 為發布檢查；CI 使用同一 runner 的 debug 簽章驗證 RC.2 → 1.0.0。公開 APK 另外使用固定 release 簽章並驗證 SHA-256。

Samsung A55 的長時間背景觀察、跨裝置加密還原及所有第三方 App 的通知相容性尚未完成實機驗證。正式版標示不代表可保證所有通知零漏記；系統遮蔽內容、工作設定檔、安全資料夾與省電限制仍可能影響記錄。
