# 1.0.0-rc.1 正式候選版

維持免費、無廣告、無帳號、MIT 開源；沿用官方固定簽章，可從 0.2.0-alpha.1 以後的官方 Release APK 覆蓋安裝。

## 本版修正

- 停用或重新設定自動備份會取消舊作業，避免舊作業覆寫新設定的成功或失敗狀態。
- 新備份讀回驗證成功後，即使無法列出或清理舊檔，仍顯示備份成功與清理未完成。
- 嚴格驗證備份整數欄位；通知或歷程識別碼與既有資料衝突時，整筆匯入交易回滾。
- 下載失敗可重新下載；程序中斷後可再次安裝；更新完成會清除安裝暫存檔。
- 主畫面與權限精靈使用相同的通知存取權判斷。
- CI 擴大至 Android 8／15／16，測試舊版透過 Android 安裝確認升級、資料保留與完成後重新開啟。

## 待完成的正式版驗收

以下項目需要在實際裝置執行；自動化測試不能替代：

- [ ] Samsung Galaxy A55／Android 16 持續 48 小時，涵蓋鎖屏、省電及重開機。
- [ ] LINE 等日常來源的新通知、更新通知及移除後紀錄；確認筆數、收藏與備註。
- [ ] 關閉記錄不再新增，重新啟用後能繼續記錄。
- [ ] 撤銷與恢復通知存取權，狀態正確；重新連線後恢復記錄。
- [ ] 以原密碼在另一部手機還原加密備份，並比較通知、歷程、收藏、備註及設定。
- [ ] 使用官方固定簽章版本覆蓋升級，確認原資料保留。
- [ ] A55 的下載、安裝確認／取消、重試、更新完成及重新開啟。

上述驗收通過並修正回報後，才發布不帶 rc 標籤的 1.0.0。無法保證所有品牌在省電或強制停止狀態下零漏記。
